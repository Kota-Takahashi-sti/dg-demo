# .claude/ — 開発用ツーリング(Claude Code 向け)

このディレクトリはデモ環境そのものではなく、**本リポジトリを Claude Code で開発・保守する
ためのサブエージェント/スキル定義**です。デモの実行・検収には不要です。

目的: セッションごとのコンテキスト(トークン)消費の削減。
長大な Web 調査結果・実行ログをメイン会話から隔離し、要約のみを扱う。

## サブエージェント(agents/)

| 名前 | 役割 | モデル |
|---|---|---|
| doc-researcher | 公式ドキュメント・バージョン調査(CLAUDE.md の必須要件)を隔離実行 | メインを継承 |
| demo-verifier | make demo-* の実行・exit code 検証・証跡保存 | Haiku(機械的作業のためコスト優先) |
| acceptance-checker | 発注者検収のシミュレーション(まっさら状態からガイドのみで再現) | メインを継承(合否判断の品質が検収に直結) |

## スキル(skills/)

| 名前 | 役割 |
|---|---|
| /verify-verbatim | ガイド出力例と証跡ログの逐語一致をスクリプトで機械検証(LLM を使わないため追加トークンほぼゼロ) |
| /record-progress | build-log.md / PROGRESS.md の定型追記フォーマット |
